About the Random Quote Generator

The Random Quote Generator is a simple web application that displays a random quote whenever the user clicks the “Generate Quote” button. JavaScript selects a quote from an array and displays it on the webpage.

The main goal of this project is to demonstrate how JavaScript can make a website interactive while helping me understand programming logic and event handling.
